THEME - CLUBS AND EVENTS

This project, titled "School Clubs & Events Hub," is a foundational, static website designed using 
only HTML and CSS to provide a clear, centralized directory for all active school clubs and a list of upcoming events.
Built entirely within a single index.html file (using an internal <style> block), the website features a modern, 
responsive layout managed by CSS Grid, a prominent navigation bar for quick access, and easy-to-read "card" components to display 
information on clubs (including meeting times and descriptions) and scheduled events (with dates and details).
Since this is a static site, there is no need for a backend, database, or complex setup; simply download the index.html file 
and open it in any web browser to view the hub.
